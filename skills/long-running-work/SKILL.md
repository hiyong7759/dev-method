# 오래 걸리는 일

1. 띄우기 전에 짧게 방향부터 사용자에게 확인한다 (끝나고서야 틀린 걸 알면 시간이 버려진다)
2. 백그라운드로 띄운다 (`Bash`의 `run_in_background`). 끝나면 하네스가 에이전트를 다시 깨우므로 따로 훅을 만들지 않았다
3. 감시는 에이전트 몫이다. 사용자가 로그를 들여다보게 하지 않고, 화면이 필요하면 `monitor-screen` 스킬
4. 검증 가능한 범위인지 판단해서, 가능한 범위까지만 작게 진행한다
