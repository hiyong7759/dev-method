# 메모리 정리

- 모든 프로젝트에 쓸 것은 이 저장소(dev-method)로, 한 제품에만 해당하는 것은 그 프로젝트 CLAUDE.md로 옮기거나 버린다
- 옮기거나 버리기 전에 사용자에게 보여 확인받는다 (메모리를 바꾸는 것은 사용자 확인 뒤)
- 남은 메모리는 에이전트의 실행 방식을 점검하는 지표로 쓴다. 같은 종류가 쌓여 있으면 훅·규칙으로 만들자고 제안한다
