# 모니터링 화면

## 원칙

- 사용자는 코드와 마크다운을 읽지 않고 화면으로 진행을 본다
- 화면은 **소스에서 자동으로 만든다.** 손으로 고친 요약은 금방 낡는다. 요청 때마다 원본(git 커밋 메시지, 진행 중 메모의 표, 로그)을 그대로 읽어 보여준다
- 보여줄 것: 변경 기록(커밋의 `결정:`/`기각:`/`검증:` 줄, 실패 커밋), 현재 상태(진행 중인 일 표, 작업 목록 상태별 개수), 오래 걸리는 작업의 로그
- 보는 사람의 권한에 따라 보이는 범위가 다르게 할 수 있게 둔다
- 화면 서버는 앱 서버와 다른 포트로 따로 띄워 서로 영향이 없게 한다

## 참고 구현

PupAI `tools/monitor/` (server.py + index.html, 포트 5190). 읽는 곳: git 커밋 메시지, `work/README.md`의 '지금 진행 중인 일' 표, `work/design-items.md` 표, `runs/logs/*.log`.
표 형식(열 이름·순서)을 바꾸면 server.py의 정규식도 함께 바꾼다.
