# 정보

- 정보 = 이름 있는 데이터 정의(타입·클래스·스키마) 한 곳. 필드마다 존재 이유를 단다(정말 필요한 정보인가의 판단 기준). 존재 이유 없는 필드는 정리 후보다
- 파생 타입은 원본에서 만든다(`Pick`, `Partial`, `Omit`). 필드 이름을 문자열로 쓸 때는 `keyof` 타입으로 묶는다
- 외부에서 들어오는 정보(API, DB)는 스키마에서 타입을 만든다
- 저장·네트워크·이벤트 접근은 타입 있는 얇은 한 층으로 모은다
- 다른 정보를 가리키는 값은 id 필드로 드러낸다. 값으로만 가리키는 약한 연결은 필드 주석에 `@ref 대상.필드`로 쓴다
