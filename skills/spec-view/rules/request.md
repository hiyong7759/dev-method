# 변경을 요청받았을 때 (채널은 자유, 기록은 반드시)

- 요청 채널은 설계서 보기의 메모(컴포넌트, 영역, 빈 영역)와 에이전트와의 대화다. 변경은 크기를 나누지 않고 사용자와 짝코딩으로 계속 이어 간다
- 메모는 한 줄이면 된다. 메모를 남길 때 화면이 순서를 안내한다: 저장 → "처리 요청 복사" → 에이전트에 붙여 넣기 → 같이 고침 → "테스트 요청"이 오면 승인 탭에서 확인
- 에이전트는 메모를 자동으로 보지 않는다. 붙여 넣기 전까지 메모는 "대기"다. 에이전트가 메모를 읽는 때는 사용자가 "처리 요청 복사"로 가져와 붙여 넣은 명령을 받았을 때뿐이다. 실시간 응답과 자동 알림은 없다
- 전달하지 않은 메모가 있으면 설계서 보기가 화면의 배너, 메모 탭, 화면 흐름 카드, 토글 배지로 "에이전트에게 알려 주세요"를 표시한다
- 사용자가 붙여 넣은 처리 요청 글에 메모 번호와 대상(컴포넌트, 영역 좌표와 가장 가까운 컴포넌트, 빈 영역의 위·아래 주변 요소)이 있다. 코드와 대조해서 답한다
- 답: `node <스킬 폴더>/memo.mjs reply <번호> --text "…" --src <소스 폴더>`. 고친 뒤: `memo.mjs applied <번호> --commit <해시> --change "바뀐 내용"`. "확인 완료"는 사용자만 바꾼다
- 대화로 요청받은 변경도 에이전트가 요청 기록(채널, 요약)을 남긴다
- 모든 변경의 커밋 메시지에 `요청:` 줄(채널과 요약)을 쓴다. 이력은 이 커밋에서 도구가 모은다
