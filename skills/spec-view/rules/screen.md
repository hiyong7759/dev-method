# 화면과 컴포넌트

- 화면 = 라우터에 등록된 라우트. 라우트 컴포넌트 위에 `@screen 이름`과 존재 이유, 사용자가 하는 일(`@does`)을 쓴다
- 라우터 밖 화면(모달, 시트)은 라우트로 올린다. 안 되면 임시 `@screen`을 쓰고 경고로 남긴다
- 화면 이동은 타입 있는 라우트 정의 한 곳에 두고, 넘기는 값의 타입을 쓴다
- 화면 안 컴포넌트는 `@spec 이름`과 `@anchor`, 존재 이유를 쓴다. 이벤트는 `@on 이벤트: 효과`로 쓴다
- 이벤트 핸들러는 이름 있는 함수로 만든다(도구가 동작 이름을 읽는다)
