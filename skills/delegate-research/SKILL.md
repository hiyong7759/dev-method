# 다른 에이전트에게 맡기기

- 맡기는 건 조사만 한다 (Sonnet·Haiku)
- 이유: 에이전트끼리 맥락을 전하고 결과를 다시 읽는 비용이 크고, 무엇을 하는지 사용자에게 보이지 않는다
- 맡긴 결과는 믿고 넘기기 어렵고, 나중에 사용자가 확인할 때 이해하기 어려워 치우는 게 일이 된다
- 구현·수정·커밋은 맡기지 않는다 (짝 코딩: 사용자가 보는 곳에서 한다)
