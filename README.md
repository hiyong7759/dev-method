# dev-method

모든 프로젝트에 쓰는 개발 방법. 계속 검증하며 고친다.

- `CORE.md` — 늘 읽히는 핵심. `~/.claude/CLAUDE.md`에서 `@/Volumes/macex/workspace/dev-method/CORE.md`로 불러온다
- `skills/` — 필요한 작업에서만 읽히는 세부. `~/.claude/skills/<이름>`에 연결(심볼릭 링크)해 모든 프로젝트에서 쓴다
  - `design-as-source` — 소스를 쓰거나 고칠 때 주석·커밋
  - `git-multisession` — 여러 세션이 한 폴더를 쓸 때 git, 위험 명령 훅
  - `monitor-screen` — 진행 상황을 화면으로 보여주는 원칙과 참고 구현

바꿀 때는 사용자 확인을 받고, 이유를 커밋에 남긴다.
